# 同一张照片，一路传下来的话

本轮依据教师反馈调整两个问题：操作文字太绕；单人视角中缺少群体说法如何形成的可见过程。保留横屏像素风、原有整体配色、音乐、碰撞音效和六键，不增加竞技评分或商业化功能。

## 一局的结构

观察四人原图 → 第一次回想 → 小林提出五人、阿禾顺着回应 → 第二次回想 → 两人引用玩家刚才的回答并回应 → 第三次回想 → 原图、三次回答、留言经过并列。

只重复人数这一件事。行走负责收集照片和避开干扰，不再追加天空颜色与旋转木马位置的测验；这些视觉元素仍留在画面里。原图始终固定，路边的五人图是被转述的版本。

## 真实回答，虚构角色

| 第二次回答 | 路边人物的回应 |
| --- | --- |
| 3 | 引用三人答案，原先的五人说法变得不确定 |
| 4 | 保留分歧，追问第五个人在哪里 |
| 5 | 引用一致答案，语气更肯定 |
| 记不清 | 保留不确定，不当成对五人的支持 |
| 尚未回答 | 不引用任何选择、不编造支持者 |

这些是明确标注的剧情人物，不是其他玩家留言、在线统计或真实群体实验。玩家可以一直选四，也可以一直选记不清。没有错误答案门槛；系统不能替玩家选错。

留言区无倒计时，停下即可阅读。输入不变，不新增阅读专用键。第一区 x=800–1200，第二区 x=1980–2440；附近的巡逻、泡泡和弹跳板避开阅读范围。护盾、照片规则和练习关照常工作。

结尾显示实际三次答案及本局出现过的留言经过。这里只能说明画面曾经显示这段话，不能证明玩家读过、相信过，或真实记忆已经改变。第三次选“记不清”时，重画的人物留空，文字明确这不代表原图零人。

## 主题与研究的边界

本作是受曼德拉效应启发的互动艺术模拟，重点呈现某个说法如何被回应、复述并获得支持。它不是对曼德拉效应全部机制的复刻，也不是诊断观众记忆的实验。

Prasad 与 Bainbridge 对视觉曼德拉效应的研究发现某些图像会引发多人一致、特定的错误回忆，并观察到自发回忆中的错误。因此不能把群体错误记忆简单等同于外部留言诱导。[原始研究摘要：The Visual Mandela Effect as Evidence for Shared and Specific False Memories Across People（2022）](https://www.psychologicalscience.org/journals/psychological-science/09567976221108944/)

作为本作“互相带偏”交互设计的相关研究方向，可另参阅 Roediger、Meade 与 Bergman 的 [Social contagion of memory（2001）](https://doi.org/10.3758/BF03196174)。本作没有复现该实验的控制条件，也不从一次答案变化推断因果关系。

## 实现与验收

- `app/memory-dialogue.ts`：独立双语对白、稳定 line id、replyTo 与纯函数分支。
- `app/LandscapeMemoryGame.tsx`：三次回想、当前留言、本局出现记录、结尾对照。
- `app/pixel-world.ts`：共用阅读区边界、正式关卡接触保护、练习隔离。
- `app/pixel-renderer.ts`：两张蓝天五人转述图，四人原图保持不变。
- `tests/memory-dialogue.test.mjs`：所有分支、两种语言、未回答及跨局数据不污染。

发布前还需真实浏览器输入通关、尺寸裁切检查和静态构建。实体摇杆与展场测试单列，不以软件测试代替。
