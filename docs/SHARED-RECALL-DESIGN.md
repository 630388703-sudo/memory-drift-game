# 同一张照片，一路传下来的话

本轮依据教师反馈调整两个问题：操作文字太绕；单人视角中缺少群体说法如何形成的可见过程。保留横屏像素风、原有整体配色、音乐、碰撞音效和六键，不增加竞技评分或商业化功能。

## 一局的结构

观察四人原图 → 第一次回想 → 沿路收集碎片，小林提出五人、阿禾顺着回应 → 第二次回想 → 两人引用玩家刚才的回答并回应 → 第三次回想 → 先检查实际带回的碎片 → 确认揭晓 → 对照原图、碎片、三次回答与留言经过。

只重复人数这一件事。行走负责收集照片碎片和避开干扰，不再追加天空颜色与旋转木马位置的测验；这些视觉元素仍留在画面里。结尾查看和揭晓不是第四次作答。原图始终固定，路边的五人图是被转述的版本。

## 为什么捡、为什么保护（2026-10-08）

开场直接给出目的：把散落的照片碎片带到终点，保住能自己核对的部分。先让玩家看原图并独立作答，再遇到人物对话；开场不提前提“他们说的那个人”。收集不是分数，保护也不是保护“正确答案”。操作区仍以短句解释怎么走、怎么按，目的说明分别放在开场、首次拾取反馈和结尾，不让玩家边走边读理论。中文和英文各自成句，但共享这条因果关系及相同的信息顺序。

- 五个固定编号对应原图从左到右的五块竖向切片，彼此互补。沿路 1–5、6–10、11–15 共三套拾取物，用 `(id - 1) % 5` 对应相同五个位置。现有 A/B/C 属性只表示在哪一段拾取，不代表真假或不同人数。
- 同号位置为空时补上，已受损时用新片修复；已有完好片时不再替换、不刷新原来的拾取时间，也不挤掉其他编号。保留更多不同的清晰碎片，就能在结尾揭晓前看清更多原图区域。
- 碰撞会丢掉最新的碎片，原位置留空；泡泡遮挡最早且仍完好的碎片，跳过已经受损的部分。空手或全部受损时不制造新碎片。遮挡不会创造新人物，也不改动原图或玩家答案。
- 保护沿用原规则：长按 0.7 秒，随后约 4 秒内挡一次碰撞或泡泡；用同一套摇杆、键盘和触屏动作。保护不会修复已有损伤，修复需要再次捡到同号碎片。
- 结尾将实际五个碎片槽保存为独立快照，首先按固定位置展示清晰、受损和缺失部分。这个查看阶段没有原图入口，Compare / C 不能提前看原图。
- 按确认键明确揭晓后，才提供原图、带回碎片和按最后人数重画的画面；这时按住 Compare / C 可临时看原图，松开返回原视图。原图固定四人；重画明确不是原图。
- 全空仍可经过查看阶段并揭晓；不以收集数量、是否答错或是否改口作为通关门槛。不把揭晓设为隐藏测验，也不宣称照片数量证明记忆是否可靠。
- 本地结果使用 `memory-drift.pixel-record.v4`；重玩不继承碎片或回答，旧版整张副本结果不混入新碎片快照。快照不是在线统计，也不是其他玩家的数据。

这里的“碎片受损”是游戏保存记录的机制，不等于曼德拉效应本身。群体说法的形成仍由两段明确标注为虚构的相互回应体现；揭晓后并列的是留存记录、三次回答和沿路转述。

## 真实回答，虚构角色

| 第二次回答 | 路边人物的回应 |
| --- | --- |
| 3 | 引用三人答案，原先的五人说法变得不确定 |
| 4 | 保留分歧，追问第五个人在哪里 |
| 5 | 引用一致答案，语气更肯定 |
| 记不清 | 保留不确定，不当成对五人的支持 |
| 尚未回答 | 不引用任何选择、不编造支持者 |

这些是明确标注的剧情人物，不是其他玩家留言、在线统计或真实群体实验。玩家可以一直选四，也可以一直选记不清。没有错误答案门槛；系统不能替玩家选错。

留言区无倒计时，停下即可阅读。输入不变，不新增阅读专用键。第一区 x=800–1200，第二区 x=1980–2440；附近的巡逻、泡泡和弹跳板避开阅读范围。护盾、照片规则和练习关照常工作。

结尾显示实际三次答案及本局出现过的留言经过。这里只能说明画面曾经显示这段话，不能证明玩家读过、相信过，或真实记忆已经改变。第三次选“记不清”时，重画的人物留空，文字明确这不代表原图零人。

## 主题与研究的边界

本作是受曼德拉效应启发的互动艺术模拟，重点呈现某个说法如何被回应、复述并获得支持。它不是对曼德拉效应全部机制的复刻，也不是诊断观众记忆的实验。

Prasad 与 Bainbridge 对视觉曼德拉效应的研究发现某些图像会引发多人一致、特定的错误回忆，并观察到自发回忆中的错误。因此不能把群体错误记忆简单等同于外部留言诱导。[原始研究摘要：The Visual Mandela Effect as Evidence for Shared and Specific False Memories Across People（2022）](https://www.psychologicalscience.org/journals/psychological-science/09567976221108944/)

作为本作“互相带偏”交互设计的相关研究方向，可另参阅 Roediger、Meade 与 Bergman 的 [Social contagion of memory（2001）](https://doi.org/10.3758/BF03196174)。本作没有复现该实验的控制条件，也不从一次答案变化推断因果关系。

## 实现与验收

- `app/memory-dialogue.ts`：独立双语对白、稳定 line id、replyTo 与纯函数分支。
- `app/memory-storage.ts`：五块固定位置碎片、同号补位与修复、完好重复片不刷新、丢片与遮挡规则。
- `app/photo-evidence.ts`：独立碎片快照与清晰 / 受损数量，不推断回答或记忆状态。
- `app/LandscapeMemoryGame.tsx`：三次回想、当前留言、本局出现记录、先查看后揭晓的结尾。
- `app/pixel-world.ts`：共用阅读区边界、正式关卡接触保护、练习隔离。
- `app/pixel-renderer.ts`：两张蓝天五人转述图，四人原图保持不变。
- `tests/memory-dialogue.test.mjs`：所有分支、两种语言、未回答及跨局数据不污染。
- `tests/memory-core.test.mjs` 与 `tests/photo-evidence.test.mjs`：三套真实拾取编号、固定位置、修复与重复片、遮挡完好片、空状态和快照隔离。

发布前还需真实浏览器输入通关、尺寸裁切检查和静态构建。实体摇杆与展场测试单列，不以软件测试代替。
