# Font sources

The interface bundles the following open-source typefaces:

- **Smiley Sans / 得意黑 2.0.1** — display headings. Copyright 2022–2024 atelierAnchor. Source: <https://github.com/atelier-anchor/smiley-sans>. License: SIL Open Font License 1.1.
- **Barlow Condensed** — English labels and display text. Source: <https://github.com/google/fonts/tree/main/ofl/barlowcondensed>. License: SIL Open Font License 1.1.

The shared OFL 1.1 text is stored in [OFL-1.1.txt](./OFL-1.1.txt).
