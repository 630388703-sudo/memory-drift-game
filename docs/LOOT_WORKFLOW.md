# LOOT 原型工作流

## 项目中的定位

LOOT 用于快速验证交互概念、视觉气氛和展览现场理解成本。正式版本仍保留在模块化源码中，以便后续接入硬件、测试和维护。

## 方法一：直接导入代码

1. 打开 LOOT 首页。
2. 选择“粘贴代码直接预览”。
3. 复制 `loot/index.html` 的完整内容。
4. 粘贴并生成预览。
5. 使用方向键和空格测试扫描、聚焦、过载和三轨移动。

## 方法二：深度创作

选择“深度创作”，粘贴 `loot/prompt.md` 中的提示词。生成后重点检查：

- 是否保持 1080×1920 竖屏；
- 是否避免霓虹赛博朋克和恐怖人脸；
- 压力不是单次 A/B 按钮，而是持续影响系统；
- 是否能在 10–15 秒内理解基本操作；
- 是否只使用规定的矛盾池。

## 迭代记录要求

每轮 LOOT 原型保留：

- 使用日期与提示词版本；
- 首页和关键交互截图；
- 发现的问题；
- 对正式代码的修改；
- 修改后的验证结果。

答辩时不要只展示“使用了 AI 平台”，而要说明 LOOT 具体帮助验证了什么，以及哪些生成结果被人工否决或重新设计。
