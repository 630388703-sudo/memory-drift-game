# 用户测试方案

## 测试目的

验证玩家能否在没有口头讲解的情况下理解压力交互，并判断“操作会改变记忆版本”的主题是否成立。

## 测试流程

1. 不解释剧情，只告知玩家可使用方向键和空格。
2. 记录玩家首次理解短按与稳定按住所需时间。
3. 观察三个扫描点和两枚走廊碎片是否出现明显卡点。
4. 游戏结束后按 `E` 导出匿名 JSON 记录。
5. 完成三个简短访谈问题。

## 访谈问题

1. 你认为照片中有几个人？为什么？
2. 你觉得自己是在恢复记忆，还是在制造一个新版本？
3. 哪一次操作最让你感觉画面被自己改变？

## 记录表

| 项目 | 内容 |
| --- | --- |
| 测试编号 | 不记录真实姓名 |
| 完成时间 | JSON 自动记录 |
| 稳定读取次数 | JSON 自动记录 |
| 过载次数 | JSON 自动记录 |
| 空白区进入次数 | JSON 自动记录 |
| 最终版本 | A / B |
| 是否理解主题 | 是 / 部分 / 否 |
| 主要卡点 | 观察记录 |

## 隐私原则

测试记录只包含游戏行为，不收集真实姓名、联系方式、账号、位置和设备标识。公开展示数据时使用汇总统计，不展示可识别个人的信息。
