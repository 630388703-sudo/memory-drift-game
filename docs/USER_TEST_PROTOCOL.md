# 用户测试清单

## 测试条件

- 1080×1920 竖屏；
- 只使用方向键 / WASD 与空格；
- 声音开启一次、关闭一次；
- 中文和英文各完成一轮关键操作；
- 首次玩家与第二位玩家各完成一局，用于检查上一观察者痕迹。

## 阶段验收

1. **准备间**：10 秒内理解“靠近再碰”；普通物件和真生物反应有区别。
2. **庭院追捕**：三轮破绽可理解；扑错产生假生物，但最多三个且不会锁死。
3. **残影跳台**：玩家能发现“跳跃产生平台”；0.35 秒反馈可见；跌落后能立即继续。
4. **声音模仿**：不开视觉辅助也能作答；开启后有清楚但不直接泄题的颜色反馈。
5. **身体拼装**：上下、左右与空格职责清楚；五个槽都能安装；无错误答案。
6. **身体试用**：至少两项玩家行为能从动作或部件状态中直接看出来。
7. **报告**：初次形态与当前形态差异明显；主导行为和上一玩家痕迹可读。

## 阻塞检查

- 任意尺寸下顶部按钮、主场景、底部提示不互相遮挡；
- 切到后台再回来不会出现巨大时间步或角色穿过平台；
- R 保留上一玩家痕迹，Shift+R 清除；
- 40 秒后报告自动返回待机；
- 全流程无死亡、Game Over、空白死循环或只能鼠标完成的操作。
