# 横屏像素版验收

## 画面与操作

- 桌面横屏 1280×800；小横屏 844×390；竖屏 390×844 菜单及转向提示。
- 英文启动、中文切换；声音开启/关闭；减少动态效果系统设置。
- 首页 → 观察原图 → 3/4/5/记不清 → 行走、跳跃、收集 → 两次回想与细节提问 → 对照 → 再看一次。
- 五格存档、覆盖最老、碰撞丢最新、干扰改动、长按保护各自反馈清晰。
- 暂停、失焦、打开设置时停止移动；回来后不保留卡住的输入。
- 六键改键等待、取消、冲突交换、重载保存；摇杆回中后才能再次移动问答选项。

## 验证记录与边界

物理/输入及照片存储/回想纯函数测试、音频测试在发布流程中运行。浏览器已检查首页到首轮回想进入关卡、暂停、操作说明、语言切换、改键等待与取消，以及上述三个布局尺寸。浏览器实测不等同于完整的实物机台通关。

六键摇杆型号、按钮实际编号、触屏多指、压力传感器、TouchDesigner容器、现场音箱及长时间连续运行仍需装置到场后测试。不要按旧竖屏文档的单键/52秒/MemoryDriftInput假定当前功能。
