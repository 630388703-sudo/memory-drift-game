# 横屏像素版验收

## 画面与操作

- 桌面横屏 1280×800；小横屏 844×390；竖屏 390×844 菜单及转向提示。
- 英文启动、中文切换；声音开启/关闭；减少动态效果系统设置。
- 首页 → 观察原图 → 第一次人数回想 → 行走/第一段虚构留言 → 第二次人数回想 → 行走/回应玩家的第二段留言 → 第三次人数回想 → 检查带回碎片 → 明确揭晓原图 → 对照 → 再玩一次。
- 第一段不引用尚未作出的第二次回答；第二段准确区分3/4/5/记不清，不能强制错误、偷偷改答案或伪装成真实玩家统计。
- 两处留言区停留不会丢照片、改照片或自动弹起；练习关的泡泡抵挡仍可完成。
- 结尾仅记录本局三次回答和显示过的留言；“出现过”不能说成“读过”“相信了”。重玩清空本局回答和留言记录。
- 五个编号固定对应原图的五个竖条区域；同号补缺或修复，完好重复片不刷新、不挤掉别的碎片。碰撞丢最新完好或受损片，泡泡只遮挡最早的完好片，长按保护的反馈与两者区分。
- 结尾先显示实际碎片，缺失和受损区域必须完全遮盖。此时无原图按钮，C不能提前揭晓；确认揭晓后才能切换原图、碎片和按回答重画。按住C临时看原图，松开恢复。重玩恢复未揭晓状态。
- 全空或全损坏也能揭晓，不新增人数题，不暗示缺失区域就是无人。“记不清”的重画留空不代表原图0人。
- 暂停、失焦、打开设置时停止移动；回来后不保留卡住的输入。
- 六键改键等待、取消、冲突交换、重载保存；摇杆回中后才能再次移动问答选项。

六键摇杆型号、按钮实际编号、触屏多指、压力传感器、TouchDesigner容器、现场音箱及长时间连续运行仍需装置到场后测试。不要按旧竖屏文档的单键/52秒/MemoryDriftInput假定当前功能。

## 访谈

1. 第一次看到照片时，你记住了什么？
2. 哪个按钮或提示让你不清楚下一步？
3. 再次回答时，你在想什么？有没有注意到自己的回答与之前不同？
4. 你注意到路边留言了吗？如果注意到，你觉得两个角色之间发生了什么？
5. 看完对照后，你如何理解照片和留言之间的差别？

访谈不预设玩家被带偏；人数始终选4、始终不确定或中途改变，都应允许。自动化通关只能证明流程与记录有效，不能替代真实参与者对主题的理解测试。
