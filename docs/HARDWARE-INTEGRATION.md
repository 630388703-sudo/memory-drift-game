# 展厅硬件接入说明

此网页通过统一输入接口连接摇杆、街机按钮或压力传感器。当前体验围绕“观察最初画面—途中再次回想—结尾对照”展开；硬件只需要提供左右方向、确认和可选的暂停，不应另行增加技能操作。

## 直接可用的标准输入

- 横向摇杆：标准 Gamepad API 的 `axes[0]`，死区为 `0.18`。
- 数字方向：Gamepad 按钮 `14/15`，或键盘 `←/→`、`A/D`、`J/L`。
- 主按钮：Gamepad 按钮 `0/1/2`，或键盘 `Space`、`Enter`。键盘编码型街机建议统一映射为 `Enter`。
- 暂停按钮：Gamepad `Start`（按钮 `9`），或键盘 `P/Escape`。

左右方向和确认在不同阶段保持同一套含义：

| 阶段 | 左右方向 | 主按钮 / 压力触发 |
| --- | --- | --- |
| 待唤醒 | 不作为推进方式 | 唤醒，进入约 3.2 秒的信号读取，再进入引导 |
| 引导与初次观察 | 在人数问题中选择 3、4 或 5 | 继续；记录人数后进入旅程 |
| 旅程进行中 | 移动角色收集照片、避开干扰 | 不触发额外能力；无需反复按压 |
| 两次回想停顿 | 选择记得的人数 | 记录当前选择并继续旅程 |
| 结果对照 | 不改变结果 | 回到最初画面的观察页，重新体验 |

旅程按有效运行时间在约 18 秒和 36 秒暂停提问，约 52 秒结束；回答与暂停期间不推进计时。人数回答只作记录，不加分、不扣分，也不判定游戏失败。压力大小不对应额外功能，按下多久也不改变行为。

## 压力传感器 / Arduino / TouchDesigner 桥接

厂家可在浏览器容器或 TouchDesigner Web Render 中调用：

```js
window.MemoryDriftInput.wake();   // 距离/压力传感器检测到观众后唤醒
window.MemoryDriftInput.move(-1); // 左移 / 向左选择，范围 -1..1
window.MemoryDriftInput.move(1);  // 右移
window.MemoryDriftInput.press(0.8); // 压力越过厂家阈值时确认一次；数值不决定功能
window.MemoryDriftInput.pause();
```

也可以派发事件，适合串口桥接脚本：

```js
window.dispatchEvent(new CustomEvent("memory-control", {
  detail: { action: "wake" }
}));

window.dispatchEvent(new CustomEvent("memory-control", {
  detail: { action: "move", value: 0.65 }
}));

window.dispatchEvent(new CustomEvent("memory-control", {
  detail: { action: "press", value: 0.82 }
}));
```

## 推荐厂家映射

1. 摇杆 X 轴归一化为 `-1..1`，中心死区建议 `0.15–0.22`。优先使用标准 Gamepad API；通过 `move` 桥接时，运行阶段可连续发送方向，人数选择阶段应以离开中位的一次拨动发送一次，回中后再接受下一次拨动，避免一次推杆跳过多个选项。
2. 压力值先做 5–8 帧移动平均；从低于 `0.55` 上升到高于 `0.55` 时只触发一次 `press`，释放到 `0.35` 以下后才能再次触发，避免连发。
3. 街机使用左右方向和一个确认按钮完成主体验；第二按钮可映射为 `pause`。保存卡片、分享与设置属于可选屏幕操作，不作为完成主体验的前提。
4. 竖屏建议 1080×1920；浏览器全屏并隐藏鼠标。网页会在其他比例中保持完整竖屏画面。
5. 第一次现场开机需通过触控或真实键盘等浏览器认可的用户手势启用声音。仅调用脚本接口不保证解除浏览器的自动播放限制；厂家应在实际容器中验证声音解锁流程。
6. 待机可由 `wake`、首次 `press`、键盘或触控唤醒；手柄使用主按钮唤醒。引导页停留约 90 秒、结果页停留约 45 秒会回到待唤醒状态；结果页也可先按确认重新观察。
7. 中文/英文可在右上角设置中切换，选择会保存在浏览器本地。

## 交付验收

- 摇杆中心静止时角色不漂移。
- 左右推满能抵达两侧收集区，但不会超出道路。
- 主按钮可完成唤醒、等待信号读取、引导、两次人数确认和结果页重新观察。
- 同一次持续压力只记录一个确认，释放后才能再次触发；人数选择不会因一次推杆连续跳变。
- 旅程仅出现照片与干扰物；收集、碰撞、确认有可辨别的音效，关闭声音后仍有相应视觉反馈。
- VERSION A 保持彩色；第一次回想后的 VERSION B 为全黑白；第二次回想后的 VERSION C 为明显紫蓝色重构。
- 约 18 秒和 36 秒出现回想停顿，回答后继续；约 52 秒显示最初四人画面及本轮三次回答的对照。
- 回想时暂停计时；不同人数答案不造成失败或奖惩；回答全部为 4 时不强行宣称记忆出错。
- 断开硬件后仍可用键盘和触控继续游戏。
- 刷新页面后本地保存的上一局记录和语言选择仍可读取；展厅浏览器不得在每轮结束时清除站点存储。

以上是接入约定和验收清单，不等同于实物验收通过。压力阈值、串口桥接、屏幕比例、声音解锁和长时间运行稳定性须在厂家实际设备上逐项测试。
