# LOOT 继续迭代约束

项目：《忘了自己是什么 / What Was I Again?》

LOOT 展示页应直接加载 GitHub Pages 最新版，不复制旧版“记忆漂移”代码。后续美术或交互修改必须保留：

1. 竖屏 1080×1920 基准与键盘完整可玩；
2. 七段流程：发现、三轮追捕、残影跳台、声音模仿、身体拼装、身体试用、观察报告；
3. 生物始终保留两个光点眼睛和右上方蓝色小尾巴；
4. 玩家行为写入 MOTION / ATTENTION / ECHO / TRACE；
5. 上一玩家只通过 localStorage 留下一个微弱特征；
6. 低饱和淡蓝、奶白、植物绿、暖黄，明快诙谐，不做恐怖、赛博朋克或黑红界面；
7. 所有图形、图标和声音必须原创或程序生成；
8. 文案先短后长：先让动作产生笑点，再显示最多一行说明；
9. 不恢复旧版照片、教室、B-307、压力条、Version A/B 或“等我一下”；
10. 不加入账号、广告、追踪、外部素材依赖或个人信息收集。

发布壳：`loot/index.html`。游戏源码以 GitHub `main` 分支为唯一版本来源。
