# LOOT 完整网页互动版提示词

请制作一款可运行的 1080×1920 竖屏网页互动原型《记忆漂移：最后一个下午 / Memory Drift: The Last Afternoon》。

玩家是“寻忆者”，进入旧教学楼 B-307 的校园记忆档案。画面风格为梦核、阈限空间、旧照片和透明档案层：米白、雾灰、灰蓝、低饱和淡紫，少量褪色黄色作为时间标记。不要黑红恐怖风，不要蓝紫霓虹赛博朋克，不要恐怖人脸或故障乱码。

当前里程碑只验证普通网页键盘操作，不接入压力传感器，也不判断按住时长。方向键或 WASD 移动扫描框、切换三条轨道；空格键每按一次发出扫描波或收集当前线索；R 键重新开始。输入模块需要保持独立，方便后续再接入压力传感器，但本版本不能让硬件逻辑阻碍网页试玩。

制作并跑通完整流程：待机旧照片 → 方向键唤醒 → Stable Archive 扫描时钟、姓名标签和第二个人影 → 自动进入 Memory Drift Corridor → 三轨移动 → 收集声音波形和照片缺失部分 → 选择 A-307、B-307 或门牌缺失的入口 → Corrupted Classroom 循环教室 → 校准时间、地点、人物三个坐标 → 重组五枚碎片 → 比较 Version A / Version B → 保存版本 → 结局反思 → 10 秒自动重置。

第一关的扫描框靠近锚点时需要出现边缘提示，按空格立即读取；三个锚点全部读取后自动转场。第二关持续向纵深推进，包含白色空缺区和三条轨道；进入空缺区不死亡，只让进度略微后退；漏掉碎片时走廊回环，直到收齐两块碎片。五块碎片总数在侧边持续可见。

第三关中，玩家用上下键选择“时间、地点、人物”，用左右键在两个合理答案之间切换，空格逐项确认。每确认一项，教室门框、时钟、椅子和人物轮廓同步改变并产生一次空间循环。碎片重组阶段用左右键选择碎片、上下键切换解释、空格放置；每枚碎片的两种位置都必须在视觉和叙事上合理。

美术需要达到毕业设计原型质量：使用原创雨天旧教室、纵深走廊和循环教室背景；叠加旧胶片扫描线、雨幕、漂浮尘埃、轻微视差、照片重影和章节标题转场。字体层级由英文衬线标题、中文宋体叙事、等宽档案标注组成，避免默认网页字体和普通矩形按钮堆叠。

玩法不能只剩菜单选择：走廊扫描要显示真假回声和隐藏路径；循环教室加入移动时间标记，玩家需要在黄色对齐窗口内按空格锁定；碎片重组使用九宫格空间移动，每枚碎片只在两个合理接口处吸附，错误位置只显示提示、不造成失败。

Version A 为 17:42、B-307、2 人、共同离开、他人拍摄；Version B 为 18:12、B-307、1 人、独自离开、定时拍摄。玩家之前的门、坐标和碎片解释累计形成行为偏向，但系统不得替玩家自动决定。左右切换版本时，人影、椅子、时钟、脚步和照片说明同步变化。保存后显示 MEMORY RESTORED / BUT ALTERED 与 ORIGINAL MEMORY: UNKNOWN。

受控矛盾只能来自：17:42/18:12、B-307/A-307、1人/2人、1把椅子/2把椅子、一组脚步/两组脚步、他人拍摄/定时拍摄、书包左侧/右侧/消失、人物完整/模糊/空白。

游戏没有死亡或 Game Over。所有视觉和声音使用原创程序图形、程序音效或清楚标记的原创占位内容。UI 以中文为主，英文为辅助。必须可以只用键盘完整通关，并适配 1080×1920 以及其他竖屏窗口。
