# LOOT 深度创作提示词

请制作一款可运行的 1080×1920 竖屏网页互动原型《记忆漂移：最后一个下午 / Memory Drift: The Last Afternoon》。

玩家是“寻忆者”，进入旧教学楼 B-307 的校园记忆档案。画面风格为梦核、阈限空间、旧照片和透明档案层：米白、雾灰、灰蓝、低饱和淡紫，少量褪色黄色作为时间标记。不要黑红恐怖风，不要蓝紫霓虹赛博朋克，不要恐怖人脸或故障乱码。

核心操作：方向键或 WASD 移动；空格短按发出扫描波；稳定按住进入 FOCUS 并减慢画面；按住过久进入 OVERLOAD，复制门、改变时间和留下人物重影。压力不是 A/B 选择按钮，每一次移动、按压和收集都要累计影响最终记忆偏向。

流程：待机旧照片 → 三步操作教学 → 在照片中扫描时钟、姓名标签和第二个人影 → 三轨记忆走廊 → 收集声音波形和照片缺失部分 → 选择 A-307、B-307 或缺失门牌 → 校准时间、地点、人物数量 → 重组 5 块碎片 → 比较 Version A 与 Version B → 保存版本 → 10 秒自动重置。

受控矛盾只能来自：17:42/18:12、B-307/A-307、1人/2人、1把椅子/2把椅子、一组脚步/两组脚步、他人拍摄/定时拍摄、书包左侧/右侧/消失、人物完整/模糊/空白。

游戏没有死亡或 Game Over。漏掉碎片时空间回环。所有视觉使用原创程序图形或原创素材。UI 以中文为主，英文为辅助。
